# ChessMaster ♚

A complete, offline chess game with a real alpha-beta engine — no backend,
no dependencies, just open it in a browser.

![Modes](https://img.shields.io/badge/modes-PvP%20%C2%B7%20PvAI%20%C2%B7%20AIvAI%20%C2%B7%20Practice%20%C2%B7%20Puzzles-blue)

## How to run

The app uses ES modules and a Web Worker, so it must be served over HTTP
(opening `index.html` directly via `file://` will not work in most browsers).

From the project folder, run **any** static file server:

```bash
# Python (preinstalled on macOS/Linux)
python3 -m http.server 8000

# …or Node
npx serve .
```

Then open <http://localhost:8000> in your browser. That's it — everything
(engine included) runs locally.

### Run the engine tests

```bash
node test/perft.mjs
```

This runs the classic **perft** move-generation validation (start position and
the “Kiwipete” torture position) plus rule-detection tests (checkmate,
stalemate, fifty-move rule, threefold repetition, insufficient material,
SAN/PGN round-trips).

## Features

### Complete FIDE rules

Every move is generated by the engine's legal move generator — illegal moves
simply do not exist in the UI:

- All piece movement, double pawn push, en passant, promotion (with a
  Queen/Rook/Bishop/Knight picker)
- Castling both sides, with full legality checks (rights, empty squares,
  king not passing through check)
- Pins, discovered checks and double checks are handled naturally: a move is
  legal only if the resulting position leaves your king safe
- Checkmate, stalemate, fifty-move rule, threefold repetition (Zobrist-based),
  insufficient material, draw agreement, resignation, and flag-fall
  (a timeout against a lone king is correctly a draw)

### A real engine (`src/ai/`)

- **Negamax alpha-beta** search with **iterative deepening** and **PVS**
- **Quiescence search** with stand-pat and delta pruning
- **Transposition table** keyed by **64-bit Zobrist hashes**
- **Move ordering**: TT move → MVV-LVA captures → promotions → **killer
  moves** → **history heuristic**
- **Null-move pruning**, check extensions, mate-distance pruning
- Tapered **evaluation**: material, piece-square tables (separate
  middlegame/endgame king and pawn tables), passed/isolated/doubled pawns,
  bishop pair, rook on open/semi-open files and the 7th rank, king pawn
  shield, mobility, center control via PSTs, development bonus, and tempo
- Small **opening book** (Italian, Ruy Lopez, Sicilian, French, Caro-Kann,
  Queen's Gambit, London, Nimzo/KID, English, Réti…)
- The engine runs in a **Web Worker**, so the UI never drops a frame while
  the bot thinks. Live telemetry: depth, nodes, eval, PV, time.

| Difficulty | Search |
| ---------- | ------------------------- |
| Easy       | depth ≤ 2, ~0.4s        |
| Medium     | depth ≤ 4, ~1.2s        |
| Hard       | depth ≤ 6, ~3s          |
| Expert     | unlimited depth, ~5s     |

### Game modes

- **Player vs Computer** — pick your color and difficulty
- **Player vs Player** — local hot-seat with draw-offer dialog
- **Computer vs Computer** — watch two bots play (pausable, per-bot difficulty)
- **Practice** — play the bot with hints (engine arrow) and free undo
- **Puzzles** — built-in tactics: find the winning line, replies auto-play

### UI

- Responsive layout (desktop / tablet / mobile), light & dark theme
- Drag-and-drop **and** click-click moving, legal-move dots, last-move and
  check highlights, coordinates, board flip
- Smooth 60 FPS piece animation (compositor-only `transform` transitions)
- Move list with SAN, history browsing (`←/→/Home/End` or click a move)
- Captured pieces with material score, player names, thinking indicator
- Fischer clocks (3|2, 5|0, 10|0, 15|10) with low-time warning and flag-fall
- Evaluation bar, evaluation graph (click to jump), procedural sound effects
- Undo / redo / restart, resign, draw offers (the bot only accepts when it
  is clearly worse!)

### Analysis & data

- **Post-game analysis**: every position is re-evaluated by the engine;
  inaccuracies (?!), mistakes (?) and blunders (??) are annotated in the
  move list, highlighted, and drawn on the evaluation graph
- **PGN export/import** (headers, comments and variations tolerated on
  import), **FEN** copy/load, custom start positions
- **Save/Load** plus automatic **localStorage autosave** — close the tab and
  your game resumes
- Optional **random named opening** start (12 classical lines)

### Why 0x88 instead of bitboards?

The board is a 128-byte **0x88 array**: off-board detection is a single AND
(`sq & 0x88`), attack loops are simple offset walks, and make/unmake is a few
byte writes with incremental Zobrist updates. In JavaScript, 64-bit bitboards
must be emulated with `BigInt` (slow) or split 32-bit pairs (complex), and in
practice a tuned 0x88 generator is competitive in JS engines while staying
readable. The generator reaches hundreds of thousands of nodes per second in
the worker — plenty for depth 7+ within the Expert time budget, verified by
the perft suite.

### Threading & cancellation

All search runs in `src/ai/worker.js`. Every request carries an id; replies
with stale ids (after undo, restart, or a new game) are discarded. This makes
cancellation race-free without terminating the worker.

| ------ | ------- |
